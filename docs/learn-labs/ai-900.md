# AI-900: Azure AI Fundamentals labs

The exam outline was updated on **2 May 2025**: generative AI is now 20 to 25% of the exam and machine learning dropped to
15 to 20%. The labs follow it. Read: all seven current exercise files for their resources, regions and tips (not every step).

## Current labs: [mslearn-ai-fundamentals](https://github.com/MicrosoftLearning/mslearn-ai-fundamentals) (updated 2026-10-02)

Every exercise starts the same way: create a **Microsoft Foundry resource and a project** (portal), pick a **region from
Microsoft's "AI Foundry recommended" list**, choose a resource group ("create or select"), and deploy a model.

| Exercise | Adds beyond the Foundry resource and project | Notes |
|---|---|---|
| 00 Explore Foundry | Nothing; explores quotas, deployments, agents | Region from the recommended list |
| 02a Generative AI | A **gpt-5-mini** deployment, an agent with file search and web search tools | Code samples use the Python `azure-ai-projects` library, run by the student |
| 03b Text analysis (25 min) | A gpt model deployment | A tip says to reuse an existing gpt deployment if there is one |
| 04a Speech (25 min) | A model deployment and **Voice mode** | A tip warns about "instant reference quota" and suggests another gpt-5 model |
| 05a Image analysis | gpt-5-mini plus a **text-to-image model** deployment | "Available models vary by subscription and region" |
| 06a Content understanding (25 min) | Content Understanding in the Foundry resource; prebuilt receipt analyzer | **Region: West US, Sweden Central or Australia East** (or the listed regions); field extraction asks to deploy models: the lab says to cancel |
| 07 Foundry IQ (20 min) | A separate **Foundry IQ resource** (a knowledge base the agent uses), with a cost acknowledgement | I did not confirm what Azure resource backs it (probably AI Search): check in a test run |

Several tips say: "depending on your permissions, you may need to **clear the option to set up recommended resources**".
That means the lab creates extra resources by default and needs extra rights to do so.

### For guardrails

- Resource types (draft): Microsoft Foundry resource (`Microsoft.CognitiveServices/accounts` with projects and
  deployments), plus whatever the "recommended resources" option adds and the Foundry IQ resource.
- **Model quota is per subscription and region.** A class of students each deploying `gpt-5-mini` can exhaust the
  tokens-per-minute quota. Plan the quota (and stagger the exercises) before class; the deployment's own tokens-per-minute
  setting is the per-student cost cap, as in the catalog's lab 09.
- Soft delete: deleting a Foundry resource keeps its name reserved (Gaia's purge handles labs it created, not student
  resources: a student's cleanup needs a purge step too).
- Regions: the union of the recommended list and West US, Sweden Central, Australia East. The list changes; do not copy
  it into policy without checking the page.

## Old labs: [AI-900-AIFundamentals](https://github.com/MicrosoftLearning/AI-900-AIFundamentals) (last updated 2024-09): **stale**

Not the current outline, but still in use by older course materials. For reference only:

- Machine learning designer labs (regression, classification, clustering): an Azure Machine Learning workspace (with its
  storage account, key vault and Application Insights) and a compute cluster of **Standard_DS11_v2**.
- Vision and language labs: an **Azure AI services** resource (Standard S0, often **East US**), Face (Free F0), Content Safety
  (Free F0), Language, Speech, a bot, Cognitive Search (Basic) with storage. Cloud Shell is used for the code.
- Free (F0) resources are limited per subscription, which a class would hit at once.

If you teach from these, say so: the exam has moved on, and the new exam's machine-learning questions are conceptual.
