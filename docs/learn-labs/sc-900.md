# SC-900: Security, Compliance and Identity Fundamentals labs

Source: [MicrosoftLearning/SC-900-Microsoft-Security-Compliance-and-Identity-Fundamentals](https://github.com/MicrosoftLearning/SC-900-Microsoft-Security-Compliance-and-Identity-Fundamentals)
(updated 2026-10-02): 14 labs plus a setup lab under `Instructions/Labs/`, and matching instructor demos. Read: a keyword extraction of eight
labs (00, 01, 03, 05, 06, 07, 09, 12) plus the file names of the rest.

## The key fact

The labs assume a **Microsoft 365 lab tenant supplied by an "authorized lab hoster"**: sign-in as
`admin@WWLxZZZZZZ.onmicrosoft.com`, pre-made users (for example Debra Berger), pre-assigned licenses (Microsoft 365 E5),
and, for the Azure labs, **an Azure subscription with pre-built resources and a role already assigned** ("this is the Azure
subscription provided by the Authorized Lab Hoster"). Lab 00 sets up the tenant (audit log, file monitoring).

This is **not reproducible in the business subscription or tenant**, and giving students the rights these labs need in a
real tenant (create users, conditional access policies, privileged identity management) would be unsafe.

| Lab | Topic | Where it runs |
|---|---|---|
| 00 Setup | Enable audit log in the M365 tenant | Microsoft 365 admin center |
| 01 Entra ID user settings (40 min) | Create a user, assign licenses | Entra and M365 admin centers |
| 02 Self-service password reset | SSPR | Entra |
| 03 Conditional Access (45 min) | An MFA policy, tested as admin and as a user | Entra |
| 04 Privileged Identity Management | PIM | Entra (this feature normally needs a premium license plan; the lab text did not say) |
| 05 Network security groups (45 min) | Create `NSG-SC900` in group `LabsSC900` and attach it to a **pre-existing VM** `sc900-winvm`; RDP test | **Azure** |
| 06 Defender for Cloud (30 min) | Explore recommendations and secure score; the default initiative is **already assigned** | **Azure** |
| 07 Microsoft Sentinel (60 min) | Create a Log Analytics workspace `SC900-Sentinel-workspace` in group `SC900-Sentinel-RG`, then enable Sentinel and set roles | **Azure** |
| 08 Defender for Cloud Apps | Explore | M365 / Defender portal |
| 09 Microsoft Defender portal (30 min) | Explore secure score and the portal | M365 Defender portal |
| 11 Service Trust Portal | Explore | Web |
| 12 Purview and Compliance Manager (35 min) | Explore | M365 / Purview |
| 13 Sensitivity labels, 14 Insider risk, 15 eDiscovery | Explore | M365 / Purview |

Only labs 05, 06 and 07 touch Azure resources, and even those expect pre-built items from the hoster (the VM, the
subscription-level Defender setup). Lab 07 creates a Log Analytics workspace with Sentinel on top, which bills per GB.

## Options (your decision)

1. **Use an authorized lab hoster** for the SC-900 labs (Microsoft's partners provide the tenants). I did not check what is
   open to an independent MCT.
2. **A Microsoft 365 developer or trial tenant** for the tenant labs. I did not verify what is available now; check
   Microsoft's pages before promising it.
3. **Instructor demos only** for SC-900. The repository has a matching demo for most labs (`Instructions/Demos/`), written
   for the instructor to project. Catalog lab 12 (clinic security) and the identity-demo card already cover the Azure and
   identity sides this way.

If you go with option 3, Gaia has nothing to guard for SC-900 students, and the catalog is the right place for it.
