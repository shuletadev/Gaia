# Claude memory for this project (mirror)

These files are a copy of the notes Claude Code keeps for this project (decisions, the owner's working style, tooling gotchas, the
state of the student sandbox). Claude's real memory lives outside the repo and does not follow you to another machine or account, so
this copy is the way to carry it. `MEMORY.md` is the index.

**To restore on a new machine or account:** open the project once in Claude Code, find its memory folder
(Windows: `C:\Users\<you>\.claude\projects\<project-folder-name>\memory\`), and copy these files into it, `MEMORY.md` included.
A fresh Claude session can also simply read `docs/HANDOFF.md`, which says the same in prose.

The mirror was taken on 2026-10-05. If the two copies differ later, the one in Claude's folder is the live one. It contains no
credentials, tenant IDs or subscription IDs.
